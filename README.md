# 🎬 Cenna-portfolio
 

Este é um projeto de site institucional desenvolvido para a **CENNA**, uma produtora audiovisual focada em criar vídeos com identidade, impacto e propósito.

---

## 📝 Sobre o Projeto
O projeto foi desenvolvido sob medida para um amigo, proprietário da produtora, com o objetivo de criar uma presença digital moderna e profissional. O site apresenta a identidade da marca, sua missão, visão, valores e portfólio de trabalhos.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização personalizada, layout responsivo (Flexbox e Grid) e variáveis para gerenciamento de cores.

## 📱 Funcionalidades
* **Design Responsivo:** Adaptado para dispositivos móveis, tablets e desktops.
* **Menu Mobile:** Navegação interativa para telas menores.
* **Identidade Visual:** Uso consistente da paleta de cores (Preto e Rosa Pink).
